# 微信定时发送助手使用说明

## 功能简介
该程序可以帮助用户在指定时间自动发送微信消息给指定好友，特别适用于需要在特定时间准时发送消息的场景。

## 运行环境要求
- Windows操作系统
- Python 3.6 或更高版本
- 微信 PC 客户端（请保持登录状态）

## 安装依赖
程序首次运行时会自动安装所需依赖，或者可以手动安装：
```bash
pip install pyautogui tkcalendar pywin32
```

## 使用步骤

### 1. 准备工作
- 确保微信已登录且正常运行
- 确保要发送的好友在联系人列表中
- 记录好友的备注名或微信名（建议使用备注名）

### 2. 启动程序
双击运行 `wechat_sender_gui.py` 或在命令行中执行：
```bash
python wechat_sender_gui.py
```

### 3. 设置发送任务
1. 在"好友名称"输入框中输入接收者的微信名称（建议使用备注名）
2. 在"发送内容"输入框中输入要发送的消息
3. 选择发送日期（点击日历图标选择）
4. 设置具体发送时间（时:分:秒）
5. 点击"开始任务"按钮

### 4. 运行过程
- 程序会自动打开好友聊天窗口
- 进度条显示距离发送时间的倒计时
- 日志区域会实时显示任务状态

## 注意事项
1. 运行过程中请勿：
   - 最小化或关闭微信窗口
   - 手动点击或操作微信
   - 移动鼠标（可能影响自动操作）

2. 时间设置：
   - 必须设置未来的时间点
   - 建议提前1-2分钟启动任务

3. 可靠性提示：
   - 建议提前进行测试
   - 重要消息建议提前测试或手动发送
   - 运行时保持电脑处于清醒状态

## 常见问题

### 1. 找不到好友
- 确认好友名称输入正确
- 确认使用的是微信中显示的名称
- 建议使用备注名而不是昵称

### 2. 发送失败
- 检查微信是否正常登录
- 确保微信窗口没有被最小化
- 检查电脑是否有其他程序干扰

### 3. 程序报错
- 确保已安装所有依赖
- 检查 Python 版本是否符合要求
- 确认微信客户端正常运行

## 技术支持
如遇到问题，请检查日志信息，常见问题包括：
- "未找到微信窗口" - 检查微信是否正常运行
- "准备聊天窗口失败" - 检查好友名称是否正确
- "发送消息失败" - 检查微信窗口状态和操作权限

## 安全提示
- 请勿发送违法或违规内容
- 建议不要发送敏感信息
- 使用时请遵守微信使用规范
